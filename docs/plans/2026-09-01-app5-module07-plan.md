# APP-5 Module 07 construction plan

## Outcome

Build the 16-hour clinician-led APP-5 leadership module that freezes the accepted Week 3 and Week 6 checkpoints, turns their exact evidence into a bounded equity recommendation, and hands a 35-point component to the final checkpoint.

The module must keep two decisions separate:

- curriculum package disposition; and
- the fictional population-health planning recommendation.

Neither decision may authorize real need determination, outreach, eligibility, funding, allocation, community action, service delivery, effect estimation, implementation, production connection, or deployment.

## Build sequence

1. Write the complete module specification, including decision classes, clinician identity boundary, workload, frozen facts, record architecture, rubric, noncompensable gates, defense, and handoff.
2. Add eight immutable controls: `.gitattributes`, `VERSION`, leadership contract, clinician profile, clinician session plan, assessment, assembler, and validator.
3. Rebuild and validate both checkpoint reference packages through their own builders, verify their accepted identities, and copy them byte for byte with both release records.
4. Create matched learner and reference leadership records. Learner records retain visible placeholders and cannot pass complete validation.
5. Preserve every Week 3 and Week 6 open condition, the rejected clustering challenger, unavailable outcomes, the transparent community-review comparison, and the not-ready intervention state.
6. Score the 35-point component once, require all leadership gates, and record a separate curriculum disposition and fictional planning recommendation.
7. Permit final-checkpoint construction only after the complete Module 07 package passes. Keep all real-world authority prohibited.

## Validation

- Two independently assembled reference candidates match byte for byte.
- The learner candidate has the same immutable manifest as the reference.
- The assembler refuses an existing target.
- Complete reference validation passes.
- Learner validation passes in learner mode and fails in complete mode.
- A copied candidate validates outside the source package.
- Deliberate mutations to checkpoint identity, evidence, recommendation, access, community rights, ML decision, conditions, scoring, gates, clinician claims, and authority are rejected.
- Python syntax, JSON parsing, link checks, central curriculum checks, version assertions, placeholder checks, portable punctuation checks, and `git diff --check` pass.
