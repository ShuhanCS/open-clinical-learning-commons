# APP-4 Module 06 implementation plan

## Outcome

Release a runnable 16-hour Module 06 package that freezes the complete Module 05 sandbox release, turns its visible and silent failures into a safety and monitoring case, and compares the accepted transparent model with one predeclared gradient-boosted challenger. The package must support the Week 6 checkpoint without choosing a clinical threshold or granting implementation authority.

## Fixed decisions

- Keep the Module 05 workspace and its 75,019-byte release manifest immutable.
- Carry the accepted Module 04 score of 25.00 points exactly once. Module 06 adds gates, not points.
- Reuse the Module 03 cohort, target, three predictors, survey weights, partitions, six candidate thresholds, missing-input rules, and evaluation rows.
- Fit one `GradientBoostingClassifier` with fixed settings and `random_state`; do not search or tune settings after inspecting holdout results.
- Retain the transparent model unless the challenger passes every predeclared calibration, discrimination, burden, missed-case, subgroup-support, drift, reproducibility, leakage, and interpretability rule.
- Keep all work nonproduction and based on historical public or synthetic teaching data.

## Build

1. Freeze and verify the full Module 05 reference workspace.
2. Generate deterministic hazards, controls, monitoring measures, incident routes, ownership, and seeded monitoring scenarios.
3. Fit and evaluate the fixed challenger on the frozen Module 03 data, including holdout, transport, threshold, subgroup, leakage, and replacement-gate comparisons.
4. Assemble learner and reference workspaces with immutable evidence, assessed records, a release manifest, and a protected Week 6 handoff.
5. Add strict validation plus deliberate failure routes for upstream mutation, hidden hazards, monitoring gaps, model leakage, threshold acceptance, score inflation, and authority expansion.
6. Write the durable 21-section module specification and update APP-4 navigation and course status.
7. Bump Commons `0.82.0` to `0.83.0`, run focused checks and the full curriculum regression, then commit and push the task files.

## Done when

- The evidence builder reproduces byte-for-byte.
- Reference and learner workspaces validate, copied validation passes, and every deliberate failure route is rejected.
- The Module 05 release identity, every prior failure, `panel-t003`, the unaccepted `0.03000000` fixture, the 25-point carryforward, and all authority limits remain exact.
- The Module 06 decision and all failed replacement criteria are visible to the Week 6 checkpoint and Module 07.
