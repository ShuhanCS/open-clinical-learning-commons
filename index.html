Healthcare data visualization / Module 04

Distributions versus summaries

Learn how chart choice changes a healthcare decision. Test a claim about emergency department performance, find what the first chart hides, and communicate the result.

About 5 minutes No coding Healthcare case Synthetic data

Learning objective

Choose a visualization that reveals both typical visits and longer waits, then write a chart title that supports a healthcare decision.
