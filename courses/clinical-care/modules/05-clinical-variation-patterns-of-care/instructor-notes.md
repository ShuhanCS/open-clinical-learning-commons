# Instructor notes

## The central contrast

Ask learners to explain why a 14.82-point site range can cross an operational threshold while the global p-value remains 0.27993975. Then ask why neither result supports a site grade. The answer must include the arbitrary synthetic labels, known direct effect of zero, uncertainty, and unmeasured workflow and clinical need.

## Do not let records become care

Stop the analysis when a learner calls a medication row adherence, a procedure row quality, no encounter no care, or an acute return preventable. Return to the numerator, denominator, source event, and missing construct.

## Use the surprising direction

People with recorded day-30 follow-up are less likely to have another scheduled record later. This is useful because it resists the expected story. Require timing displacement, catch-up care, clinical composition, and measurement as alternative explanations before any improvement discussion.

## Module 06 boundary

Module 05 names an equity question but does not calculate demographic differences. It names a prospective improvement lever but does not build the driver diagram or implementation measures. It hands off a transparent benchmark but does not fit machine learning.
