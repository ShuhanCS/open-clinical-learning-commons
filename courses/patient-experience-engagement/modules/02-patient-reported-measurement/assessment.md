# Module 02 measurement assessment

Submit the 13 editable records in a workspace assembled by `build_workspace.py`. Preserve every immutable file and run the validator before submission.

## Required decision

State whether an exact patient-reported item set is ready to enter Module 03 response and representation work. The decision must name the instrument, version, items, construct, scoring rule, skip logic, language and mode plan, proxy and burden rules, rights boundary, and unresolved conditions.

## Scoring

| Criterion | Points |
|---|---:|
| instrument fit and construct/content validity | 4 |
| scoring correctness and reproduction | 4 |
| reliability and meaningful interpretation | 4 |
| language, mode, proxy, access, and burden | 4 |
| source, rights, claims, reproducibility, and responsible agent use | 4 |
| Total | 20 |

Passing requires at least 16 points and all 18 gates. The accepted score is frozen into the Week 3 checkpoint.

A changed instrument, wrong response state, shared denominator, fabricated validation claim, unsupported meaningful-change threshold, missing accessible route, invalid CAHPS naming, synthetic-as-real claim, hospital ranking, or unauthorized progression fails regardless of points.
