# Mode, coverage, and access interpretation

Mail, phone, and web are independently assigned by the deterministic teaching generator. The released frame counts are 443 mail, 422 phone, and 390 web. The respondent counts are 245, 247, and 290. Because the response formula contains a programmed mode term, the synthetic pattern is useful for checking calculations and planning access routes.

It is not evidence that web causes higher response in real patients. A real design must consider preference, language, disability, literacy, proxy use, connectivity, contact quality, burden, and refusal. The 100 percent teaching coverage says only that every selected public row was placed in the constructed frame.
