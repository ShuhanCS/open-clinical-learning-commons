# AI-use record

- AI use: an agent assisted with code, synthetic workflow construction, record drafting, consistency checks, and validation routes.
- Human-owned decisions: intended use, access needs, workflow interpretation, burden assumptions, design recommendation, stop conditions, progression, and every clinical boundary.
- Protected evidence: the agent did not change the accepted Week 3 source, logic, model, calibration, threshold, score, gate, or progression records.
- Prohibited agent action: the agent may not select or accept a clinical threshold, infer clinician motive, fill a suppressed equity cell, recommend care, score a real patient, approve silent mode, implement, or deploy.
- Verification: deterministic builders, manifests, source hashes, invariant checks, learner and reference validation, and deliberate failure routes.
- Remaining review: named workflow, human-factors, clinical, patient, language-access, disability-access, equity, privacy, accessibility, responsible-AI, and independent-reproduction review before alpha.

AI-assisted text and code remain drafts until a qualified human accepts them. Package validation is not clinical approval.
