# AI-use record

- Tools used: `agent-assisted drafting and deterministic Python generation`.
- Agent role: `draft structure, generate fixed teaching evidence, and run reproducibility checks`.
- Human-owned decisions: `hazard acceptability, monitoring triggers, clinical meaning, model replacement, threshold acceptance, progression, restart, retirement, and every clinical or production decision`.
- Verification: `source hashes, invariants, complete validator, deliberate failure routes, and named human review`.
- Prohibited agent actions: `changing intended use, accepting a threshold, hiding a failure, scoring a real patient, starting silent mode, implementing, connecting production, or deploying`.

## Disclosure

The release records the fixed model settings, source identities, generated outputs, decision rules, failed rules, and verification routes. Agent output is evidence for review, not an autonomous clinical or governance decision.
