# Module 06 assessment

Module 06 adds no course points. It supplies required safety, monitoring, governance, and embedded-ML gates for the cumulative Week 6 package.

| Component | Points available | Points added here |
|---|---:|---:|
| Module 04 workflow, burden, and equity review | 25 | 25 counted once |
| Module 05 sandbox and failure-mode gates | 0 | 0 |
| Module 06 safety, monitoring, governance, and ML gates | 0 | 0 |
| Cumulative Week 6 package | 25 | 25 counted once |

All 22 Module 06 gates must pass. Points cannot compensate for changed upstream evidence, a hidden hazard, an ownerless or actionless measure, a missing unavailable state, leakage, tuning, an accepted threshold, an overwritten failure, score inflation, or expanded clinical or production authority.
