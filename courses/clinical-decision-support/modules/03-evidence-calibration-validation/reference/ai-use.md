# AI use

- Tool role: assisted with deterministic code, test, table, and curriculum drafting.
- Data boundary: only public NHANES files, synthetic Module 02 data, and repository materials were used.
- Human-owned decisions: intended use, cohort, target, predictor list, threshold acceptance, clinical interpretation, subgroup claims, progression, and every clinical-use boundary.
- Independent checks: every inherited source hash is verified; two clean evidence builds are byte-identical; 20 invariants pass; committed evidence matches a clean rebuild; learner and reference workspaces receive independent validation.
- Agent prohibitions: no diagnosis, threshold selection or acceptance, subgroup action, real-patient score, clinical alert, order, implementation, production connection, or deployment authority.
- Accountability: APP-4 faculty and named clinical, methods, survey, calibration, equity, patient, accessibility, responsible-AI, and independent reviewers remain responsible for acceptance.

The agent-generated draft does not substitute for named human review. Any changed clinical or analytic decision invalidates the affected evidence and requires a full rerun.
