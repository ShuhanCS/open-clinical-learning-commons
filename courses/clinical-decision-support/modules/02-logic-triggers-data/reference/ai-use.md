# AI-use record

- AI or agent use: assisted with source inspection, deterministic code drafting, fixture enumeration, documentation structure, and validation checks.
- Human-owned decisions: clinical purpose, hook suitability, input meaning, terminology, lookback, target, predictors, model, threshold, card wording, patient consequence, progression, implementation, and deployment.
- Agent authority: none for clinical purpose, clinical correctness, target, predictor, eligibility, threshold, alert, patient score, clinical action, implementation, or deployment.
- Verification: exact source hashes, complete FHIR parsing, duplicate counts, patient linkage, fixture contents, expected traces, placeholder checks, copied-answer checks, authority boundaries, and full curriculum regression.
- Prohibited use: no real patient or workplace data entered an AI system.
- Known limit: generated prose and code can be internally consistent while clinically wrong; named human reviewers must inspect every clinical, terminology, safety, and governance decision.
