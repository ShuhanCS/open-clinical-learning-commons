| ID | Criterion | Points |
|---|---|---:|
| E01 | Correct evidence, product, and claim boundary | 8.00 |
| C01 | Clinical CDS reasoning, patient consequences, workflow, safety, and access | 9.00 |
| L01 | Leadership recommendation, evaluation readiness, alternatives, and ownership | 8.00 |
| G01 | Monitoring, stewardship, governance, disagreement, and communication | 6.00 |
| H01 | Reproducibility, accessibility, responsible agent use, and defense | 4.00 |
| Total |  | 35.00 |

Passing requires at least 28.00 points, all 26 gates, an adequate 14-question defense, an allowed package disposition, and an allowed CDS recommendation.

The course total is `40 + 25 + 35 = 100`. The final checkpoint does not duplicate any earlier component.
