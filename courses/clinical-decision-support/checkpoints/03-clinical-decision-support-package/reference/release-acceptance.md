## Allowed use

The package may be used for curriculum construction, instructor preparation, named review, learner rehearsal, and independent reproduction.

## Prohibited use

Real-patient scoring, clinical threshold acceptance, clinical alerting or action, silent-mode evaluation, implementation, production connection, and deployment are prohibited. The package cannot support a claim of local clinical benefit, utility, safety, equity, workflow fit, interoperability, or approval readiness.

## Change and stop rules

Any changed candidate byte requires a new Module 07 version and rebuilt final package. A changed release identity, hidden failure, waived accessibility block, unsupported claim, unavailable-as-zero statement, missing owner, failed gate, incomplete defense, unreviewed tag, or false authorization stops acceptance.
