# Instructor notes and answer key

## Teaching decision

Keep asking what visual claim each exact table supports. Accessibility is part of analytic correctness: a reviewer must be able to recover the values, structure, uncertainty, and limit without relying on color or sight alone.

## Review sequence

1. Verify all four upstream fingerprints.
2. Ask the learner to trace one mark from each figure to an exact CSV field.
3. Check F01 denominators 374 and 379 and distinguish structural from seeded missingness.
4. Recalculate F02 RT01 and RT06 labels and preserve the Wilson interval definition.
5. Reconcile F03 quarter totals to 374, emergency 314, and inpatient 60.
6. Remove color mentally and verify hatch, line, marker, label, and table alternatives.
7. Read the three alternatives without figures and compare high, low, source, period, and limit.
8. Review grayscale, resize, zoom, and reading-order records.
9. Confirm N01 through N08 and the synthetic, unadjusted, selected-cohort boundaries.
10. Review reproduction, AI disclosure, and final disposition.

## Common interventions

- If all missingness is called bad, return to field-specific state rules.
- If F02 rows are summed, restore the RT01 parent relation and differing windows.
- If an interval becomes a significance test, return to descriptive arithmetic.
- If the connected quarters become a trend claim, remove the claim or add an approved model in a later course.
- If orange or blue carries meaning alone, require a redundant cue and exact alternative.
- If only PNG is submitted, require SVG and exact CSV.
