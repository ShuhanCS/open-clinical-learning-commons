# Release notes

Version 0.1.0 is the first FND-1 reproducible toolkit candidate for the health-system analytics engineering lead. It is compatible with Checkpoint 2 version 0.1.0 and Modules 04 through 06 version 0.1.0.

The release preserves 35 accepted evidence artifacts, ten cumulative checkpoint records, four checkpoint provenance files, and 23 source-code and environment files. It adds release identity, a data brief, limitations, a material AI audit, a prompt log, a 35-point score draft, a checklist, validation, and technical-defense records.

The toolkit is assembled and validated from a clean target. Accepted evidence remains byte-identical. Named human review and macOS or Linux reproduction remain conditions. The package is for public synthetic technical education and downstream method development only. It supports no production, real clinical, operational, population, trend, forecast, process-control, effect, or causal claim.

A changed immutable artifact, upstream version, required path, source, grain, denominator, access route, or claim boundary requires a new version decision and renewed review.
