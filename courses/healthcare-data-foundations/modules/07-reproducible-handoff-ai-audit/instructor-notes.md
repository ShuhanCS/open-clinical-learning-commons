## Review order

1. Scan for prohibited data, archives, databases, caches, credentials, and local paths.
2. Verify release identity, Checkpoint 2 progression, package tree, and manifest.
3. Trace one artifact from each owning module.
4. Verify analytic grain and fingerprint.
5. Review D01 through D20 and N01 through N08 handoff.
6. Reconcile one rate and one figure to exact evidence.
7. Inspect the 23 pipeline-source files and reproduction record.
8. Review the data brief, limitations, change log, and release notes.
9. Review the prompt log and independently repeat the material AI audit.
10. Run complete validation, review the checklist, and conduct the defense.
11. Score, record every gate, and set the disposition and conditions.

## Common interventions

- Output copied without source ownership: use the manifest and pipeline contract.
- Changed output accepted by appearance: require exact bytes and SHA-256.
- New orchestration code changes defaults: remove it and use the accepted stage builders.
- Structural blank becomes zero: trace N03 and VP14.
- Synthetic interval becomes significance: restore descriptive wording.
- Quarterly sequence becomes a decline claim: restore selected-index chronology.
- AI log says only "used for help": require claim, consequence, independent method, evidence, result, action, and owner.
- Tag predates review: require the reviewed commit and authorized annotated tag.
- Validator pass is treated as approval: require named reviewers and defense.
