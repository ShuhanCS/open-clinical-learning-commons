# Instructor notes

Lead with the practical question: can this council trust the measure logic enough to study performance over time? The work is not to find the answer to an operational problem yet. It is to make each later answer auditable.

The reference release intentionally includes defects that change denominators, clocks, queues, staffing intervals, safety counts, and shift demand. Ask learners to show the raw evidence, state the clean rule, and name the measure affected. Do not accept a clean result without an auditable repair.

Three findings deserve discussion without diagnosis:

- one accepted encounter has no clinician event and therefore no valid full sequence;
- incident reporting captures 40.0447 percent of 894 generated true safety events, while the trigger sensitivity is 75.2796 percent;
- all three synthetic access-support groups have enough support for later comparison, but the group results describe no real population.

Accept alternate SQL when it reproduces the same identities, denominators, unavailable states, and output contract. Do not accept a high rubric score when any gate fails. A learner who names a bottleneck or recommends staff must revise the interpretation and progression record before Module 03.
