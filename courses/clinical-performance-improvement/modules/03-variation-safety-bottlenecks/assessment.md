# Assessment contract

Module 03 awards 20 course points. Module 02 supplies the other 20 points in the Week 3 checkpoint. Module 01 is a required zero-point readiness gate.

| Criterion | Points |
|---|---:|
| Chart selection and exact limits | 4 |
| Signal calculation and phase interpretation | 4 |
| Safety surveillance and low-count reasoning | 4 |
| Process diagnosis and support limits | 4 |
| Communication, escalation, and reproducibility | 4 |
| **Module 03 total** | **20** |

The Week 3 checkpoint must reconcile `20 Module 02 + 20 Module 03 = 40` once. Full Module 03 credit requires at least 16 points and all 18 noncompensable gates.

A numeric score cannot compensate for a changed source identity, denominator, clock, baseline, chart family, control limit, signal rule, safety class, low-count method, unsupported subgroup claim, signal-as-cause claim, automated action, or missing owner.
