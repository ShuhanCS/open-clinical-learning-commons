# Module 07 assessment

Module 07 drafts the 35-point clinical performance improvement package. Checkpoint 03 records it once.

| ID | Criterion | Points |
|---|---|---:|
| E01 | Correct evidence, decision, and claim boundary | 8.00 |
| C01 | Clinical performance reasoning, safety, access, and workforce judgment | 9.00 |
| L01 | Leadership recommendation, feasibility, alternatives, and ownership | 8.00 |
| M01 | Monitoring, stewardship, escalation, disagreement, and communication | 6.00 |
| H01 | Reproducibility, accessibility, responsible agent use, and defense | 4.00 |
| Total |  | 35.00 |

Construction review requires at least 28.00 points, all 26 gates, an adequate 14-question defense, and one allowed recommendation.

The reference earns 35.00 of 35.00 for package completeness. Its clinical recommendation remains `revise before testing`. A complete curriculum package does not authorize a test or implementation.

The 26 gates in `gate-results.csv` are noncompensable. A strong score cannot compensate for changed accepted evidence, hidden failure, unsupported authority, missing ownership, absent disagreement, inaccessible communication, or hidden agent use.
