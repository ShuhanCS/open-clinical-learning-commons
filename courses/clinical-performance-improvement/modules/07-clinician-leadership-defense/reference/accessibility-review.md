# Accessibility review

- Frontline brief uses plain language: `pass`.
- Leadership summary states one decision and authority boundary: `pass`.
- Technical terms are defined in place or linked to exact evidence: `pass`.
- Every upstream chart has an accepted exact table or structured text route: `pass`.
- Monitoring dashboard has semantic headings and an exact table: `pass`.
- Color is not the only state carrier: `pass`.
- CSV records have headers and one declared row grain: `pass`.
- Unavailable values use text rather than blank or color-only state: `pass`.
- Units, periods, denominators, thresholds, owners, and limits remain in text or tables: `pass`.
- Defense supports live, recorded, written, or supported oral routes with the same 14 questions: `pass`.
- Narrow-screen dashboard support is retained: `pass`.
- External scripts, fonts, and assets in the dashboard: `none`.
- Remaining named accessibility review: `pending before alpha`.

Equivalent access does not mean reducing the evidence standard. Every route must preserve the same exact facts, decision limits, questions, and follow-up challenge.
