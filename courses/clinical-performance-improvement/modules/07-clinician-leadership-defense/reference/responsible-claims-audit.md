# Responsible claims audit

| Claim risk | Result | Retained language |
|---|---|---|
| Synthetic evidence described as real operations | pass | fictional service and synthetic records |
| Public hospital linked to the fictional service | pass | linkage prohibited |
| Signal described as cause | pass | signal opens human review |
| Incident reports described as prevalence | pass | undercapture and false positives retained |
| Bottleneck described as root cause | pass | bounded constraint; root cause not established |
| Forecast described as guaranteed demand | pass | point and empirical range for planning |
| Forecast or capacity described as staffing requirement | pass | staffing recommendation not authorized |
| Simulation described as causal effect | pass | assumption-testing evidence only |
| Partial scenario result described as selection | pass | selected scenario remains none |
| Safety or return described as favorable | pass | not simulated and prospectively unavailable |
| Access or workforce gap imputed as zero | pass | unavailable stays unavailable |
| Feasibility gap described as favorable | pass | requires local evidence stays open |
| Dashboard described as live control | pass | static planning artifact with no automatic alerting |
| Feature importance described as cause | pass | model allocation only |
| ML near miss rounded into acceptance | pass | R01 fails at 0.731788 versus 0.750000 |
| Curriculum acceptance described as test authority | pass | recommendation is revise before testing |
| Staffing schedule clinical automated test implementation scoring or deployment authority | pass | all prohibited |

The audit checks the leadership records. It does not substitute for named clinical, safety, workforce, access, governance, responsible-AI, or independent review.
