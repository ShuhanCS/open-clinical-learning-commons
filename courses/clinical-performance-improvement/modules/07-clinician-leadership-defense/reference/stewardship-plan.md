# Evidence and decision stewardship plan

| Asset | Steward | Review cadence | Change route | Decision limit |
|---|---|---|---|---|
| Service charter and unit of flow | APP-3 faculty owner and data steward | each course release | return to Module 01 | fictional teaching service only |
| Measures and event logic | measurement lead | each source or definition change | return to Module 02 | denominator and clock changes require a new release |
| Signals, safety, and diagnosis | quality and safety lead | each new data period | return to Module 03 | signal is not cause and reports are not prevalence |
| Forecast target, folds, and method | forecasting reviewer | each forecast release | return to Module 04 | forecast does not set staffing |
| Scenario contract and evaluation | improvement methods lead | each redesign | return to Module 05 | simulation is not causal effect |
| Feasibility and monitoring | clinical performance council | each redesign review | return to Module 06 | local evidence gaps remain gaps |
| Dashboard | accessibility and measurement leads | each data or design change | accessibility and exact-table review | static planning artifact only |
| ML contract and decision | ML reviewer | each challenger release | new fixed contract and confirmation period | failed R01 remains failed |
| Leadership package | Module 07 faculty owner | each candidate release | rebuild from accepted checkpoints | no upstream byte may change |
| Final disposition | final checkpoint panel | official half-term end | Checkpoint 03 review | package status does not grant clinical authority |

Every material change receives a semantic version, source record, exact evidence path, reviewer, and renewed gate decision. A changed upstream fact cannot be patched only in leadership prose.
