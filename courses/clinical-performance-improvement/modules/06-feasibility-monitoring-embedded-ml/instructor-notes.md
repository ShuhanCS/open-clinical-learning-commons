# Instructor notes

## Teaching purpose

This module teaches two kinds of restraint. First, learners must turn a no-selection scenario result into a useful monitoring and leadership package without forcing an option. Second, they must retain a promising ML challenger as a failed replacement when one predeclared rule misses by a small amount.

Do not reveal the reference metrics before learners freeze the model and eight replacement rules. Ask them to predict which evidence would be enough to change the planning input and why all-rules logic matters.

## Suggested facilitation

1. Start with the Module 05 handoff. Require learners to say `none` before discussing feasibility.
2. Give each group one scenario and seven feasibility domains. Unknowns must remain unknown.
3. Recombine groups to specify the 12 measures, including three prospectively unavailable values.
4. Test the dashboard at narrow width and with color descriptions removed.
5. Trace one temporal fold. Draw the issue-time boundary and identify why target-week rolling values leak.
6. Run the fixed challenger once. Do not tune.
7. Apply R01 last. The class should see seven passes before the MAE near miss.
8. Have learners defend why the transparent method remains accepted even though most metrics improve.
