# Prospective evaluation design

- Evaluation status: `design only`
- Causal effect status: `not established`
- Process-monitoring measures: `12`
- Threats requiring active audit: `8`
- Implementation authority: `not authorized`

If a later team revises an option and receives approval for a bounded test, it should first stabilize the measure definitions and collect a prospective baseline. Weekly median arrival-to-clinician time should use an XmR display. Left-before-seen should use a p-chart. P90 wait, cycle time, throughput, utilization, overtime, safety events, 72-hour returns, access gaps, and workforce burden should remain separate outcomes.

A pre/post mean difference alone is not a causal design. The team must record adoption, crossover, concurrent interventions, calendar time, case mix, missingness, and measurement changes. Any stronger effect claim requires an authorized design and supporting evidence. Simulation output may set expectations and stop rules, but it cannot substitute for observation.
