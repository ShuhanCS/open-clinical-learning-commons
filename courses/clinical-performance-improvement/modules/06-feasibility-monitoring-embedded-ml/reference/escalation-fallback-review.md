# Escalation and fallback review

- Escalation rules: `10`
- Automatic actions: `0`
- Fallback state: `continue no-change monitoring`
- Restart condition: `new evidence, clinician leadership review, and explicit authorization`
- Draft threshold status: `planning rules; not control limits`
- Rollback authority: `not established in this release`

Each rule names a trigger, response level, confirmer, decision owner, immediate safeguard, fallback, documentation location, and restart condition. Safety candidates receive immediate clinical review. Access or high-acuity thresholds receive pause review. Other thresholds trigger investigation or an interpretability gate. Nothing routes a patient, changes staffing, starts a test, or automates an action.
