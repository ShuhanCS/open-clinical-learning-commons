# Module 04 instructor notes

Start with the forecast contract, not the winning error table. Learners should be able to say what was known at each issue time and identify all 21 target shifts before discussing method performance.

Require all three methods on the same 28 folds and 588 rows. The selected smoothing model wins on MAE, but its error distribution remains operationally wide. Preserve under- and over-forecast consequences separately.

The 0.96 clinician-hour conversion is a historical baseline planning anchor. It is not a staffing requirement, productivity standard, or adequacy finding. Little's Law is a rough consistency check because the accepted fields do not satisfy a stationary single-queue mean-value system.

Stop review if a learner uses future flags as predictors, treats the special-event period as removed noise, hides a failure slice, recommends staffing, introduces machine learning, or changes the Week 3 evidence.
