# Module 05 instructor notes

Require learners to trace one paired replication before reading the scenario summary. The same arrival and patient-profile realization must enter S00 through S03 within a condition.

The model is guided and intentionally bounded. Its 20 percent effective-service factor represents intermittent clinician work inside a longer clinician-to-departure interval. It is not a productivity estimate. The 2-night, 6-day, and 4-evening slot schedule is a calibrated teaching assumption, not an observed staffing count.

Stop review if a learner changes the accepted forecast, deletes a failed condition, interprets unmodeled safety or return outcomes as favorable, hides an access or workforce tradeoff, or treats simulation as evidence that a real intervention will work.

The 25 points belong to Module 05 once. Module 04 and Module 06 remain required gates but add no Week 6 points.
