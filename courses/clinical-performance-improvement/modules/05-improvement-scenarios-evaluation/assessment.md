# Module 05 assessment

Module 05 carries the full 25-point forecast, scenario, and evaluation source assignment. The accepted Module 04 forecast is a required zero-point input and is not scored again.

## Point map

| Criterion | Points |
|---|---:|
| Frozen forecast and scenario contract | 3 |
| Model validation and conservation | 5 |
| Scenario comparison | 5 |
| Sensitivity and tradeoffs | 4 |
| Evaluation design and threats | 5 |
| Reproducibility, communication, and responsible AI | 3 |

All 20 gates must pass. Points cannot compensate for changed upstream evidence, failed conservation, an omitted scenario or sensitivity, hidden failed runs, missing access or workforce evidence, a favorable claim for an unmodeled safety or return outcome, or implementation language.
