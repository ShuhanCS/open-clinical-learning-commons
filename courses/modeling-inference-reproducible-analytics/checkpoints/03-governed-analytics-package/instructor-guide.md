# Instructor guide

## What this checkpoint decides

The review makes two separate decisions:

1. Is the package complete, reproducible, accessible, and honestly bounded?
2. What use may the fitted model support?

Do not let a passing package imply clinical use. The reference package passes with conditions while the model remains for teaching only because the held-out test has four positive outcomes and half of the subgroup rows are suppressed.

## Review sequence

1. Confirm the official half-term end date.
2. Validate the exact 168-file Module 07 candidate.
3. Assemble into a new target and inspect the 168-row freeze.
4. Confirm the three accepted release fingerprints.
5. Review the six score rows and all 27 gates.
6. Conduct the 15-question defense.
7. Confirm reviewer independence and condition ownership.
8. Record package disposition and model-use recommendation separately.
9. Run complete validation against the exact reviewed state.
10. Authorize the annotated tag only after named human acceptance.

## Human review remains essential

Automation can confirm paths, fingerprints, counts, arithmetic, and required decision fields. Reviewers must decide whether explanations, clinical meaning, accessibility, independent checks, condition ownership, and the recommendation are credible.

Reference reviewer names describe curriculum-construction coverage only. Replace them with actual reviewers for learner assessment. The reference package must not be represented as completed live program approval.
