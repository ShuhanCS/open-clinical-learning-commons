## Prediction unit and outcome

- Grain: one selected index encounter per synthetic person.
- Prediction time: end of the index encounter.
- Outcome: `acute_return_90d`, equal to 1 when an emergency or inpatient return starts within 90 days after the index encounter stops.
- Horizon: 90 days.
- Population: the frozen 374-person modeling cohort.
- Training rows: 224, including 25 outcomes.
- Validation rows: 75, including 7 outcomes.
- Test rows: 75, including 4 outcomes.

The date-ordered partition is never re-split. Validation selects the eligible candidate and threshold. Test is opened once after both are locked.

## Allowed model inputs

`LOG01` uses three declared transformed fields from Module 02:

- `age_centered_decade`;
- `prior_365d_acute_count`; and
- `index_class_inpatient`.

`ML01` uses five numeric fields and four categorical fields available at prediction time:

- numeric: age and four prior-year count fields;
- categorical: gender, race, ethnicity, and index class.

The selected pipeline standardizes numeric fields and one-hot encodes categorical fields. Both steps are fit on training rows only. The fitted transform produces 15 columns. Unknown later categories are ignored rather than causing test-time failure.

## Prohibited critique fields

`LEAK01` intentionally uses `next_30d_state` and `endpoint_90d`. Both contain information after prediction time or derived from the outcome window. It exists only to show that implausibly strong performance can be a data error. It is rejected before performance is considered and can never be selected.

## Missingness

The nine eligible fields used by `ML01` are complete in this frozen teaching cohort, so no imputer is fit. If a later version introduces missing allowed predictors, the missingness rule and training-only imputer must be added to the contract and versioned before fitting.

## Source boundary

The records are generated by Synthea and do not represent real patients. Counts and model results are deterministic instructional fixtures. They cannot establish clinical effectiveness, external validity, fairness, safety, or deployment readiness.
