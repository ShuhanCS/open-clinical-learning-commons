# Instructor notes

## Teaching focus

The central lesson is that technical package acceptance and model-use permission are separate. The reference candidate can be technically complete while the model remains teaching-only because the test set has four outcomes, uncertainty is wide, subgroup evidence is sparse, validity conditions remain, and no prospective clinical evidence exists.

## Review order

1. Validate the nested Checkpoint 2 package and candidate manifest.
2. Trace the model card and performance appendix to exact evidence.
3. Review subgroup, validity, forecast, and claim limits.
4. Review ten monitoring signals and governance actions.
5. Review retraining, rollback, stop, retirement, and safe fallback.
6. Review reproduction, AI, accessibility, human, reviewer, and condition records.
7. Score six criteria and adjudicate 18 gates.
8. Conduct the handoff and ten-question defense.
9. Record package disposition and model use on separate lines.

## High-value probes

- Ask why 0.58802817 does not establish stable discrimination.
- Ask what 48/23/2/2 means for threshold consequences.
- Ask why five suppressed subgroup rows prevent fairness ranking.
- Ask why monitoring thresholds are simulated review triggers, not validated operating limits.
- Ask what safe fallback remains when rollback to an older model is not defensible.
- Ask which agent statement was rejected and what independent evidence retained the bounded statement.

## Reference boundary

The reference sign-off applies only to curriculum construction. A real learner submission requires actual learner and reviewer names, a live defense, and named program review before alpha.
