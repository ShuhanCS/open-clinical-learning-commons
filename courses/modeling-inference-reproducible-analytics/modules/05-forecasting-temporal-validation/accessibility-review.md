# Accessibility review

The forecast SVG embeds a title and description, uses high-contrast lines, and is supplemental. `forecast-text-alternative.md` states the pattern and final fold in prose. `forecast-predictions.csv` contains every exact plotted value, model label, horizon, actual, error, and reporting percentage.

No task requires color perception, mouse interaction, or reading coordinates. Tables use explicit units and model identifiers. If SVG rendering is unavailable, the CSV and Markdown routes contain the complete assessable evidence.
