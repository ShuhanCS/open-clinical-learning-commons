# Instructor notes

## Teaching purpose

This module changes the learner's default question from "Which model fits?" to "Which claim is defensible?" Keep the cases separate. Their deliberate variety forces learners to name the unit, time zero, selection process, dependence, and quantity before interpreting a coefficient.

## Suggested sequence

1. Begin with the five-row analytic-aim map and require claim classification before code.
2. Build the DAG from timing and clinical assumptions, then compare it with the structured reference.
3. Reveal known synthetic truth only after learners state the unadjusted bias direction.
4. Compare overlap and balance before adjustment estimates.
5. Treat the complete-case route as a population change, not merely a software option.
6. Place 2,400 rows beside 600 people before showing repeated-model uncertainty.
7. Reconstruct one Kaplan-Meier risk set by hand before reading Cox output.
8. End with the specialist-referral table and progression decision.

## Misconceptions to probe

- A good prediction score does not identify a treatment effect.
- A variable associated with exposure and outcome is not automatically a confounder.
- A propensity score is not a substitute for design.
- Weighted balance is evidence about measured covariates, not proof of exchangeability.
- Imputation is not recovered truth.
- More rows do not create more independent people.
- A hazard ratio is not a probability or a fixed-time risk ratio.
- Censored does not mean outcome equals zero or record should be deleted.

## Scoring

Score the 15-point rubric only after all 13 gates pass. A technically polished package with an unsupported causal or survival claim is returned. The strongest defense names exactly what each fixture demonstrates and where it stops.

The reference disposition is not a shortcut for grading. Learners may defend `revise` or `stop` if their reasoning is coherent and their evidence remains unchanged.
