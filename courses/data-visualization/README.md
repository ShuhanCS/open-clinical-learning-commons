# Data visualization

This course teaches learners to choose, build, critique, and explain healthcare visualizations based on the decision, the data structure, the audience, and what the display leaves out.

- Source course: DA-730, Analyzing, Visualizing, and Storytelling with Data
- Course designer: Ali Goff
- Commons status: course structure and first module record published
- First lab environment: R and ggplot2

## Source record

Ali Goff's full redesign document is preserved as a [Markdown source record](../../docs/source/ali-goff-da-730-course-redesign.md). The source record includes the rationale for the redesign, course architecture, eleven-module inventory, module contract, scaffolding model, and complete Module 04 example.

## Course structure

The course separates four elements:

1. A durable module owns one visualization competency.
2. A healthcare case applies that competency in a specific setting.
3. A course wrapper provides the seven-week schedule, discussions, and exams.
4. Coding scaffolds support different levels of R experience without changing the concept sequence.

Eleven modules fill thirteen teaching slots:

| Slots | Module |
|---|---|
| 1 | Encoding and the grammar of graphics |
| 2 | Perception and the accuracy ranking |
| 3-4 | Chart selection in practice |
| 5 | Distributions versus summaries |
| 6 | Rates, denominators, and adjustment |
| 7-8 | Uncertainty and variation |
| 9 | Color |
| 10 | Time |
| 11 | Comparison and small multiples |
| 12 | Maps and geography |
| 13 | Audience, annotation, and composition |

Misleading displays, accessibility, equity, ethics, and small-cell protection are assessed inside the modules where they affect a real decision.
