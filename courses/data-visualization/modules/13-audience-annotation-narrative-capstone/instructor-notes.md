# Module 13 instructor notes

## Teaching purpose

Module 13 completes DA-730 by teaching evidence-preserving audience adaptation. Learners use one source chain for two audiences, produce the final decision package, and defend its values, definitions, limitations, and requested action.

The module is not a general presentation workshop. Every narrative choice remains accountable to the exact table and source record.

## Opening question

Ask: Which sentence must remain true in both audience versions?

A useful answer states a source-supported finding and action boundary. A style preference is not an invariant.

## Why this reference case

The case is useful because:

- one public signal is visually strong;
- the evidence is intentionally historical;
- a review action is supported;
- an intervention action is not supported;
- technical and executive readers need different detail;
- the same exact table can anchor both; and
- overstatement is easy to diagnose.

The facility selection is for curriculum clarity, not public criticism.

## Claim ladder key

### Source value

CMS reports OP-22 at 23 percent for the selected 2024 period.

### Finding

The selected value is the highest observed among 53 reporting Massachusetts hospitals and crosses the mock course review trigger.

### Interpretation

The historical public signal warrants validation. It does not establish current performance.

### Recommendation

Open a local definition and current-data review.

### Authorized action

Assign the quality director and require current local evidence at the next committee review.

## Critique key

### C1: overstated causality

The source contains no staffing exposure, local time series, intervention, or causal design. Repair the title, state the historical source, and request validation. A staffing analysis would need current local operational data, temporal design, definitions, confounding review, and clinical and operational governance.

### C2: hidden freshness

The flawed card calls the value current and removes the period, release date, and lag. Restore all three and change the action from intervention to current local data review.

### C3: annotation misdirection

The large arrow and alarm title dominate. The threshold origin and freshness boundary are unreadable. Restore hierarchy to source value, time, threshold origin, and action.

## Common learner errors

### Writing an axis-label title

`OP-22 by hospital` names the display but does not state the finding. Ask what the audience should notice and what boundary prevents overclaiming.

### Writing a causal title

Return to the source design. Require the learner to name the exposure, comparison, time order, and confounding strategy that would be necessary.

### Removing limits for an executive audience

Executive brevity does not permit a misleading action. Keep the material limit near the decision request.

### Adding a redundant supporting figure

Ask which different question it answers. If none, remove it.

### Changing the number while simplifying

Compare both outputs with the exact table. A rounded value may be acceptable only when documented and not decision-changing.

### Hiding source age in a footnote

For this case, age changes the action. It belongs in the primary hierarchy.

### Replacing uncertainty with confidence language

Require source-supported uncertainty terms. Persuasive certainty is not a substitute for evidence.

### Treating defense as performance

Reward accurate refusal of unsupported claims. Confidence that expands the claim loses credit.

## Accessibility review

Check:

- title and body readability;
- values and units;
- non-color cues;
- line-pattern labels;
- grayscale survival;
- logical reading order;
- exact table;
- equivalent alternatives;
- resize and print;
- slide export;
- spoken visual description; and
- no hover-only evidence.

## Equity and action language

The public file has no subgroup evidence. Require learners to state that limitation and avoid implying uniform experience.

Do not blame patients for leaving before being seen or clinicians for an aggregate signal. Current review should examine system conditions and access factors when governed local data permit.

## AI-use review

Require specific verification evidence:

- exact-table comparison;
- definition comparison;
- source URL check;
- cross-audience number check;
- cross-audience claim check;
- visual inspection;
- accessible-alternative comparison; and
- human decision record.

A generic statement that the learner checked AI output does not pass.

## Reproducibility review

The record should let another user:

1. obtain the same source release;
2. verify checksums;
3. run the analysis;
4. regenerate both figures;
5. regenerate the exact table;
6. compare the alternatives;
7. inspect versions; and
8. confirm output names.

## Oral defense scoring

Full credit requires that the learner:

- explains the decision in one sentence;
- identifies the source and population;
- traces the key value;
- distinguishes finding from interpretation;
- explains the material limitation;
- defends the primary and supporting figure choice;
- explains audience adaptation;
- explains accessibility;
- explains AI verification; and
- refuses unsupported expansion.
