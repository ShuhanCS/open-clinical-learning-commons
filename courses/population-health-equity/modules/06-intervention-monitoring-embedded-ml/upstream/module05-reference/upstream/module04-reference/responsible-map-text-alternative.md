# Text alternative for the responsible teaching map

The map covers all 1,620 census tracts in the official 2024 TIGER/Line Massachusetts tract layer. It displays 1,597 CDC PLACES modeled crude adult diabetes prevalence estimates for measure year 2023 from the 2025 tract release. Twenty-three tracts have no accepted PLACES row and remain unavailable.

The map uses five fixed absolute classes. Eighty-two tracts are below 5.0%. Eight hundred twenty-six are from 5.0% to below 10.0%. Six hundred eight are from 10.0% to below 15.0%. Sixty-four are from 15.0% to below 20.0%. Seventeen are 20.0% or greater. The unavailable class contains 23 tracts.

Forty-nine mapped tracts are hatched for classroom support review because their model interval is at least 4.0 percentage points wide, their retained PLACES population field is below 500, or both. This is a course review rule, not a CDC quality label or exclusion rule. Read the exact estimate, interval, population field, support state, and claim limit in `tract-map-table.csv`.

The 14 county values in `county-aggregation.csv` are population-weighted teaching summaries of tract estimates. They are not official county PLACES estimates. When each tract class is compared with its county summary class, 645 of 1,597 tracts change class. This shows that aggregation changes the displayed pattern. It does not show that one geographic scale is correct or describe the health status of every person in an area.

Read the map in this order:

1. Confirm the public source, measure year, release, and modeled-estimate label.
2. Use the fixed percentage-point legend. Gray means unavailable.
3. Treat hatching as a prompt to inspect the exact interval and population field.
4. Use the complete tract table for exact values and unavailable states.
5. Do not infer individual risk, community need, priority, eligibility, or an action rule.

The map is a teaching display. It is not an observed-case map, disparity finding, needs assessment, ranking, target list, eligibility list, outreach plan, funding rule, allocation rule, intervention, implementation record, or production system.
