# AI-use record

AI assistance may help draft code, SQL, table structure, plain-language alternatives, and candidate wording. A human must run every source, handoff, rule, consequence, sensitivity, score, gate, and workspace check and compare the result with the declared contract.

The reviewer must record what was checked, which source and output identities were used, and which suggestions were rejected. AI cannot certify that a modeled value is need, choose a fairness definition, infer community preference, reconstruct suppressed values, select a rule, authorize contact or service, waive appeal, make a pause or stop decision, or replace the accountable owner.

For the accepted reference, assistance was limited to curriculum drafting, deterministic code, SQL, validation wording, and record structure. Human verification remains required before alpha for every domain, community, access, fairness, and governance judgment.
