# Decision and resource contract

## Decision

The classroom decision is: which, if any, transparent fictional targeting rule is responsible enough to enter Module 06 intervention planning?

The candidate universe is the 1,597 accepted tracts with a CDC PLACES modeled diabetes prevalence estimate. The public estimate, interval, population field, support state, source release, and claim limit remain unchanged. The fictional capacity and community-review layer adds teaching assumptions. It does not add real facts about a community.

## Resource constraint

Each rule receives 280 fictional program places. The build divides them into 28 ten-place teaching awards. Partial awards and carryover are prohibited. All four rules use the same candidates, public evidence, synthetic layer, award size, accountable owner, and interpretation limits.

Every rule selects 28 tracts and leaves 1,569 unselected. These are classroom results. A selected row is not eligible, funded, contacted, served, endorsed, or authorized.

## Public and synthetic roles

The accepted PLACES value is a modeled area-level estimate. It is not observed cases, individual risk, community need, or consent. The synthetic layer supplies fictional capacity, travel, staff, access, review, objection, unresolved-question, and burden states. It is not a description of a real local program or community.

## Authority

The accountable owner is the `FMA-DP-01 fictional resource-allocation owner`. That owner must keep rule criteria visible, receive objections, correct errors, reopen review, pause when access or capacity is unresolved, and stop if a classroom result is represented as real authority.

The module permits rule comparison and a provisional planning recommendation. Real eligibility, outreach, funding, allocation, community action, service delivery, implementation, production connection, and deployment remain prohibited.
