# Later evaluation proposal

## Question

If a future intervention were ethically authorized and implemented, did accessible navigation improve completion of a validated diabetes-prevention pathway without worsening access, burden, or withdrawal rights?

## Design proposal

APP-6 should define the causal contrast, assignment mechanism, eligibility process, follow-up window, outcome definitions, missing-data strategy, interference assumptions, equity estimands, and stopping rules before any outcome is observed. A prospective stepped or randomized design may be considered only if community, clinical, operational, privacy, and ethics review support it.

## Required outcomes and balancing measures

Potential outcomes include validated program completion and a clinically appropriate later outcome. Balancing measures include language and disability access, travel, burden, withdrawal, incidents, missingness, and differential follow-up. Area-level modeled prevalence is context, not a participant outcome.

## Current conclusion

Module 06 provides no effect estimate. Its outcome field is intentionally unavailable, the dry run contains no participants, and the fictional intervention is not implementation-ready. APP-6 owns causal identification and effect estimation.
