# Dry-run interpretation

The dry run reconciles all 280 fictional places to 280 unique test records. Fifty tests are held because five carried areas are staff-not-ready. The remaining 230 exercise response, scheduling, access, attendance, completion, fidelity, burden, feedback, objection, incident, escalation, and pause logic.

The run contains 14 simulated objections and 23 incident tests. All objection tests trigger a pause. Every incident has a named route, and every required pause is honored. Six measures still trigger review, including readiness, travel, offer processing, language access, disability access, and incident-free operation.

These results test whether the design exposes failure and routes responsibility. They do not measure participation, service quality, clinical outcome, benefit, harm, or effectiveness. All outcome fields are unavailable by design, so an effect estimate would be fabricated.
