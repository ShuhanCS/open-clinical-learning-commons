# Pause, stop, revision, and retirement

Pause the affected fictional pathway when staff are not ready, required language or disability access is unavailable, an objection is unresolved, a privacy near miss occurs, an incident lacks a route, or a required denominator is unavailable.

Stop the release if a record causes real-world action, if a model changes selection or allocation, if learner work hides a trigger, if synthetic records are described as people or outcomes, or if effect, implementation, production, or deployment claims appear.

Revision requires a named owner, a dated change, a repeated dry run, and a new evidence review. Do not revise features, cluster count, transformations, seeds, or thresholds merely to make the challenger pass.

Retire the candidate when access or safety failures cannot be corrected, community review withdraws support, data stewardship cannot be maintained, the intervention premise no longer fits the decision, or a better transparent design replaces it. Retirement is a valid result.
