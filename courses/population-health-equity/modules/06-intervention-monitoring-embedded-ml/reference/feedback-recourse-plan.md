# Feedback and recourse plan

Anyone represented in a later fictional exercise must be able to ask a question, correct information, refuse, withdraw, appeal, disagree, or request a stop without penalty. Community representatives must be able to challenge the planning premise, the access plan, the monitoring design, the threshold response, or continued use of the candidate.

The dry run includes supportive, question, no-feedback, and objection states. An objection creates a hold and community review. It does not become a negative label, reduce access, or train the model. Questions and corrections go to the community accountability owner. Access complaints also go to the relevant access owner. Privacy concerns go to the privacy owner and program steward.

The program steward records the response, the owner, the correction, and whether the design was paused, revised, stopped, or retired. A closed record requires a human explanation. Silence is not consent, and no-response is not refusal.
