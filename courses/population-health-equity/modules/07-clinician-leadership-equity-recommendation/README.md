# APP-5 Module 07: Clinician leadership and equity recommendation

This 16-hour clinician-led block turns the accepted APP-5 population, disparity, place, targeting, intervention, monitoring, and ML evidence into a bounded leadership recommendation, community-facing summary, accountability record, stewardship plan, conditions register, and defense.

The reference curriculum package is `accept with conditions`. Its separate fictional planning recommendation is `recommend seeking approval for bounded structured community review`. The intervention is not ready for real use. No need determination, community contact, outreach, eligibility, funding, allocation, service, effect estimation, implementation, production connection, or deployment is authorized.

Joe Joseph, MD, SFHM, is the designated clinician of record. The dated public biography and confirmation boundary are in `clinician-profile.md`.

## Build and validate

```powershell
python assemble_candidate.py --target <new-folder> --reference
python validate_candidate.py --candidate <new-folder> --complete
python assemble_candidate.py --self-check
python validate_candidate.py --self-check
```

For learner assembly, first build and validate accepted Checkpoint 01 and Checkpoint 02 packages, then run:

```powershell
python assemble_candidate.py --checkpoint1 <week3-folder> --checkpoint2 <week6-folder> --target <new-folder>
python validate_candidate.py --candidate <new-folder>
```

The assembler refuses an existing target. It freezes both complete checkpoints and both release records in a 1,301-row immutable manifest. The 26 leadership records remain editable until review.
