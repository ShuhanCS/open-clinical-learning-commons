# AI use record

- Agent used: `yes, for bounded drafting and code assistance`.
- Human-owned decisions: source identity, geography, measure, display classes, support-review rule, aggregation method, map framing, ecological and contextual interpretation, accessibility acceptance, claim boundary, progression, and any later targeting rule.
- Agent-permitted work: draft code, compare exact schemas, calculate hashes, run declared checks, format tables, and propose text for human review.
- Agent-prohibited work: change the source, geography, measure, interval, unavailable state, class breaks, support rule, county weighting, map framing, claim boundary, score, gate, progression, community response, target, eligibility, allocation, intervention, implementation, or deployment decision.
- Verification: source fingerprint, checkpoint handoff, SQL results, geometry facts, SVG structure, exact tables, scores, gates, claims, and deterministic builds receive independent checks.
- Sensitive data supplied to an agent: `none`.
- Fabricated community input: `none`.
- Agent-authored real-world recommendation: `none`.

An agent cannot interpret a map color as need, vulnerability, priority, eligibility, or permission to act. Human reviewers remain accountable for the teaching release and may require revision, pause, referral, or withdrawal.
